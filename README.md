# 🌐 E-Portfolio - นายณัฐชนน สินธำรงรักษ์

แฟ้มสะสมผลงานออนไลน์ (Electronic Portfolio) ของ **นายณัฐชนน สินธำรงรักษ์** นักเรียนชั้นมัธยมศึกษาปีที่ 6 แผนการเรียนศิลป์ธุรกิจการค้าสมัยใหม่ โรงเรียนธัญรัตน์

## 📋 รายละเอียดภายในเว็บไซต์
- **หน้าแรก (Home):** แนะนำตัวและข้อมูลการศึกษาเบื้องต้น
- **แนะนำตัว & ทักษะ (About & Skills):** ข้อมูลส่วนตัว ความสนใจด้านคอมพิวเตอร์และกีฬา
- **ผลงานโค้ด (Projects):** รวมผลงานการพัฒนาเว็บไซต์และซอร์สโค้ด
- **กิจกรรม (Activities):** ประวัติความสนใจและกิจกรรมด้านต่างๆ

## 💻 ผลงานโค้ดที่เชื่อมโยง
1. **เว็บไซต์ E-Portfolio ส่วนตัว (`index.html`):** พัฒนาด้วย HTML5, CSS3 และ JavaScript รองรับการแสดงผลทั้งคอมพิวเตอร์และมือถือ (Responsive Design)
